# ASCEND · AI-Powered Orchestration (HITL demo)

Static one-page mock for **step 3** of the ASCEND journey: pipeline execution with **human-in-the-loop / expert review**. Built with **PrimeNG Lara Light Blue** (CDN), **PrimeIcons**, and **Roboto** — UI copy in **English**.

## Run locally

Open `index.html` in a browser (double-click or serve the folder with any static server).

## Repo autocontenido (Git)

Sube **`index.html`** y los archivos **`ascend-*.css`**, **`ascend-lazy-reveal.js`**, **`Arganologo.png`**, **`icon-lightbulb.svg`** en la **raíz** del repo (sin subcarpetas).

PrimeNG 17 se carga por CDN; hace falta internet al abrir la pantalla.

## Design

- Layout aligned to ASCEND mocks: `max-width: 1280px`, `22px` horizontal padding, `14px` gaps.
- Orange / amber accents for **expert gates** and **HITL** items (see plan).
- Does **not** modify the separate **Migration Path Planning** project.
